# Java Core Exercises & OOP: Assignment prompts and solutions
A collection of introductory Java assignments focusing on algorithm implementation, static vs. instance methods, numeric edge cases, and class design.
# Exercises Breakdown
----------------------------------------------------------------
# Exercise 1: Prime Number Checker (App1a.java, App1b.java)
Implementation of prime number verification demonstrating the difference between instance-based and static method calls.
# Exercise 2: Factorial & Combinations Calculator (App2.java)
Mathematical computation of n! and combinations binom(n,k) with basic input validation.
# Exercise 3: Safe Factorial with Integer Overflow Detection (App3.java)
Enhanced factorial calculation that detects Integer.MAX_VALUE overflow using long precision and returns an error code.
# Exercise 4: Quadratic Equation Solver (App4.java)
Solving ax^2 + bx + c = 0 using Java's Math library, handling real solutions and negative discriminants.
# Exercise 5: Fibonacci Sequence Membership Checker (App5.java)
Command-line application verifying whether an integer belongs to the Fibonacci sequence by generating intermediate terms.
# Exercise 6: Bank Account OOP Class (Account.java)
Object-oriented model of a bank account featuring private attributes, constructor initialization, deposits, withdrawals, interest application, and formatted toString() output.
# Exercise 7: Interactive Bank Account CLI Application (App7.java)
A console menu interface allowing users to create an Account instance and perform interactive banking operations.
