# Java Core Exercises & OOP: Assignment prompts and solutions
![Java](https://img.shields.io/badge/Java-ED8B00?logo=openjdk&logoColor=white)
![Level: Beginner Friendly](https://img.shields.io/badge/Level-Beginner%20Friendly-brightgreen)
> A collection of **introductory `Java assignments`** focusing on algorithm implementation, **static vs. instance methods**, **numeric edge cases**, and **class design**.
---

## Exercises Breakdown:
### **Exercise 1: [Prime Number Checker](<./1. prime numbers/>)**
* **Files:** `App1a.java`, `App1b.java`
* **Description:** Implementation of prime number verification demonstrating the difference between instance-based and static method calls.
* **Documentation:** [📄 Assignment Prompt (PDF)](<./1. prime numbers/assignment.pdf>)
---
### **Exercise 2: [Factorial & Combinations Calculator](<./2. factorial - combinations/>)**
* **File:** `App2.java`
* **Description:** Mathematical computation of $n!$ and combinations $\binom{n}{k}$ with basic command-line input validation.
* **Documentation:** [📄 Assignment Prompt (PDF)](<./2. factorial - combinations/assignment.pdf>)
---
### **Exercise 3: [Safe Factorial with Integer Overflow Detection](<./3. factorial - combinations - enhanced (number overflow check)/>)**
* **File:** `App3.java`
* **Description:** Enhanced factorial calculation that monitors numeric boundaries and detects `Integer.MAX_VALUE` overflow using 64-bit precision (`long`), returning error codes when capacity is exceeded.
* **Documentation:** [📄 Assignment Prompt (PDF)](<./3. factorial - combinations - enhanced (number overflow check)/assignment.pdf>)
---
### **Exercise 4: [Quadratic Equation Solver](<./4. quadratic equations solving/>)**
* **File:** `App4.java`
* **Description:** Solves $ax^2 + bx + c = 0$ using Java's `Math` **library routines**, **handling real roots**, **double roots**, and **negative discriminants**.
* **Documentation:** [📄 Assignment Prompt (PDF)](<./4. quadratic equations solving/assignment.pdf>)
---
### **Exercise 5: [Fibonacci Sequence Membership Checker](<./5. fibonacci number membership verification/>)**
* **File:** `App5.java`
* **Description:** Command-line application verifying whether a given integer belongs to the Fibonacci sequence by generating intermediate terms iteratively.
* **Documentation:** [📄 Assignment Prompt (PDF)](<./5. fibonacci number membership verification/assignment.pdf>)
---
### **Exercise 6: [Bank Account OOP Class Model](<./6. bank accounts CLASS IMPLEMENTATION - deposit - withdraw - balance/>)**
* **File:** `Account.java`
* **Description:** Object-oriented model of a bank account featuring data encapsulation (private attributes), private fields, constructor initialization, deposit/withdrawal methods, interest accrual, and formatted `toString()` output.
* **Documentation:** [📄 Assignment Prompt (PDF)](<./6. bank accounts CLASS IMPLEMENTATION - deposit - withdraw - balance/assignment.pdf>)
---
### **Exercise 7: [Interactive Bank Account CLI Application](<./7. bank accounts APPLICATION/>)**
* **File:** `App7.java`
* **Description:** A console-based interactive menu interface that instantiates `Account` objects and executes transactional banking operations at runtime.
* **Documentation:** [📄 Assignment Prompt (PDF)](<./7. bank accounts APPLICATION/assignment.pdf>)
---
